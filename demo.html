Program Mapper

A working demo of the tool behind our evaluation pipeline.

The program and figures in the demo are fictional. The application works best on a large screen.

Open the demo in a new tab
Using the app

Six views of one program

Move between them from the rail down the left side of the demo. Each one looks at the same program from a different angle.

Stakeholder map

Who is around the program—funders, staff, partners, the people it serves — and how they are tied to one another.

Logic model

Inputs through activities and outputs to short-, medium- and long-term outcomes, with each pathway on its own layer and the layers added up into the whole program.

Theory of change

The assumptions each causal link depends on, and the evidence filed under each one, with every link marked evidenced, mixed, untested or refuted.

Policy

The rules regulating the program today, the changes in development, and which of the program's measures each one affects.

Change

Outputs and outcomes projected year by year under changes to inputs and policy, with every scenario read against a baseline.

Data

Every number in the model, held once as a series and traced to each place it is used.
